agentic system（代理式系統）
工作流與代理的統稱 —— 任何由 LLM 協助推動多步任務的系統。
Workflow（工作流）
LLM 與工具透過「你寫好的、預先定義的程式路徑」被編排。
Agent（代理）
由 LLM 動態主導自己的流程與工具使用，以完成任務。
Augmented LLM（被增強的 LLM）
共用的基礎構件：被檢索、工具、記憶增強過的模型。
Gate（關卡）
提示鏈步驟之間的程式化檢查，用來驗證中間結果是否合格。
Sectioning（分節）
平行化的變體：把任務切成獨立子任務同時跑。
Voting（投票）
平行化的變體：同一任務跑多次，取共識。
Orchestrator（協調者）
中央 LLM，在執行時把任務拆成子任務並彙整結果。
ReAct
推理＋行動：思考 → 行動 → 觀察的迴圈（Yao 等，2023）。
Reflexion
口語自我反思，讓代理在多次迭代中改善（Shinn 等，2023）。
Handoff（交接）
在去中心化的多代理系統中，一個代理把控制權交給另一個。
Manager pattern
中央管理者代理透過工具呼叫協調各專門代理（代理即工具）。
Guardrails（護欄）
明確的限制與檢查，讓代理在安全範圍內運作。
ACI（代理—電腦介面）
Agent-Computer Interface：代理使用的工具文件／簽名 —— 要仔細設計。
