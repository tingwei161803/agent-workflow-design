核心概念：Workflow 與 Agent

進入六種模式之前：什麼是「agentic system」、它們共用的基礎元件、何時該用哪種，以及為什麼不同來源對「有幾種模式」說法不一。

link

1 · 提示鏈 Prompt Chaining

工作流 · 把任務拆成固定的循序步驟，每步 LLM 呼叫處理上一步的輸出，中間可加檢查。

alt_route

2 · 路由 Routing

工作流 · 先把輸入分類，再分派給專門的後續處理 —— 不同的提示、工具鏈或模型。

account_tree

3 · 平行化 Parallelization

工作流 · 同時跑多個 LLM 呼叫再彙整結果。兩種變體：分節（sectioning）與投票（voting）。

hub

4 · 協調者—工作者 Orchestrator–Workers

工作流 · 由中央 LLM 動態拆解任務、分派給工作者 LLM，再彙整它們的結果。

rate_review

5 · 評估者—優化者 Evaluator–Optimizer

工作流 · 一個 LLM 產生回應，另一個評估並回饋，形成迴圈 —— 反覆迭代精修。

smart_toy

6 · 自主代理 Autonomous Agents

代理 · 沒有固定路徑。LLM 在迴圈中規劃並行動，靠工具與環境回饋自我導向達成目標。
